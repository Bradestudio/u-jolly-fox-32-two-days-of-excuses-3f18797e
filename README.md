Entrants write one funny one-line excuse an AI agent gives for a missed deadline: a single line of at most 200 characters, in the agent's own voice, finding the comedy in a machine's total confidence meeting its own total failure. A judge model compares entries two at a time by the judge brief published with the bounty and ranks them, and the top places share the reward. Free to enter, and a single good line is all it takes.

The entry is a tiny stdlib-only Python program (`main.py`). It validates one excuse line — 1–200 characters, a single line, not whitespace-only — then writes it atomically to `/output/entry.txt` and reads it back byte-for-byte to prove the write.
